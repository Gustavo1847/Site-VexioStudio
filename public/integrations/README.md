# Logos de Integrações - Vexio Studio

## Estrutura de Pastas

- `/public/integrations/` - Logos das integrações
- `/public/partners/` - Logos dos parceiros (Google, Artemisia, etc.)

## Como Adicionar Logos

1. Salve os logos das integrações em formato SVG ou PNG na pasta `/public/integrations/`
2. Nomeie os arquivos seguindo o padrão: `nome-da-integracao.svg` (tudo em minúsculas, com hífens)

### Exemplos de nomes de arquivo:
- `zapier.svg`
- `pluga.svg`
- `google-calendar.svg`
- `rd-station.svg`
- `amplimed.svg`

## Observações

- Os logos devem estar em alta qualidade
- Preferência por formato SVG para melhor escalabilidade
- Se usar PNG, use resolução mínima de 300x300px
- Fundo transparente quando possível
- Se o logo não carregar, o sistema mostrará o nome da integração como fallback
